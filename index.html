Политика конфиденциальности

Дата последнего обновления: 21 февраля 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности описывает, как приложение TaxMama («Приложение», «мы») собирает, использует и защищает персональные данные пользователей («вы», «пользователь»).

Используя Приложение, вы соглашаетесь с условиями настоящей Политики. Если вы не согласны с её условиями, пожалуйста, не используйте Приложение.

2. Какие данные мы собираем

  • Данные компании — название организации, ИНН, ФИО руководителя, юридический адрес, контактные данные (email, телефон, Telegram). Вводятся вручную в разделе «Настройки» и хранятся исключительно на вашем устройстве.
  • ИНН для проверки — ИНН, который вы вводите для анализа налоговых рисков. Запрос направляется к открытым данным ФНС, ФССП и арбитражных судов.
  • Загружаемые документы — файлы (PDF, изображения), которые вы загружаете для анализа в разделе «Сканер». Передаются на сервер для обработки и не хранятся после завершения анализа.
  • Аудиозаписи — записи, создаваемые в разделе «Запись диалога». Хранятся локально на устройстве. При запросе анализа передаются на сервер для транскрипции и обрабатываются немедленно.
  • Сообщения чата — текст сообщений в AI-консультанте. Передаётся на сервер для генерации ответа.
  • Технические данные — версия ОС, модель устройства, версия Приложения. Используются для диагностики ошибок.

3. Как мы используем данные

Мы используем собранные данные исключительно для:

  • предоставления функций Приложения (анализ рисков, сканирование документов, AI-консультации);
  • улучшения качества Приложения и исправления ошибок;
  • обеспечения технической поддержки.

Мы не используем ваши данные для рекламы, не передаём их третьим лицам в коммерческих целях и не продаём.

4. Хранение данных

Данные компании и настройки хранятся локально на вашем устройстве в защищённом хранилище (AsyncStorage). Мы не имеем доступа к этим данным без вашего ведома.

Данные, передаваемые на сервер для обработки (документы, аудио, сообщения чата), не сохраняются на сервере после завершения обработки запроса.

История проверок ИНН и реестр документов хранятся исключительно на вашем устройстве.

5. Разрешения устройства

Приложение запрашивает следующие разрешения:

  • Микрофон — для записи аудио в разделе «Запись диалога». Запрашивается только при первом использовании функции записи.
  • Камера — для фотографирования документов в разделе «Сканер». Запрашивается только при использовании функции съёмки.
  • Фотогалерея — для загрузки изображений документов из галереи устройства.

Вы можете отозвать любое разрешение в настройках вашего устройства в любое время.

6. Безопасность данных

Мы применяем технические и организационные меры для защиты ваших данных: передача данных осуществляется по зашифрованному протоколу HTTPS, локальные данные хранятся в защищённом хранилище устройства.

Тем не менее, ни один способ передачи данных через интернет не является абсолютно безопасным. Мы не можем гарантировать абсолютную защиту данных.

7. Права пользователя

В соответствии с Федеральным законом № 152-ФЗ «О персональных данных» вы имеете право:

  • получить информацию об обработке ваших персональных данных;
  • потребовать исправления неточных данных;
  • потребовать удаления ваших данных;
  • отозвать согласие на обработку данных.

Для удаления всех локальных данных используйте кнопку «Сбросить все настройки» в разделе «Настройки» Приложения. Для удаления серверных данных обратитесь к нам по контактам ниже.

8. Дети

Приложение предназначено для использования лицами, достигшими 18 лет. Мы намеренно не собираем данные детей до 18 лет. Если вам стало известно, что ребёнок предоставил нам персональные данные, пожалуйста, свяжитесь с нами.

9. Изменения политики

Мы оставляем за собой право обновлять настоящую Политику. При существенных изменениях мы уведомим вас через Приложение. Продолжение использования Приложения после публикации изменений означает ваше согласие с обновлённой Политикой.
